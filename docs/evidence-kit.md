## 1. 問題の核（3行で）

札幌市の65歳以上人口は **56.7万人（29.4%）** に達し、**高齢単身世帯は12.2万世帯**。公的な「福祉除雪」制度は
要介護認定などの要件が厳しく（令和8年度からは要介護度が要件）、**約500m以内に頼れる子・親族がいない世帯**しか対象にならない。
一方で雪道の転倒による救急搬送は**毎年約1,900人**、除雪作業中の死亡事故は**毎年発生**しており、
「自力で雪かきができない人」と「手伝いたい人」の間に、公的制度では埋まらない隙間がある。

### 2.2 公的制度（福祉除雪）の隙間 — これがプロダクトの出発点

| 項目 | 内容 | 出典 |
|---|---|---|
| 制度の目的 | 自力で除雪が困難な高齢者・障がい者の「出入口+玄関までの通路」を地域協力員が除雪 | [S2][S6] |
| 対象要件（R8年度〜） | 要介護1以上等の**認定者だけで構成される世帯**等（従来の「年齢」要件から変更） | [S2] |
| 対象要件（共通） | **約500m以内に除雪を援助できる子・子の配偶者がいない**世帯 | [S2] |
| 利用実績 | **R6年度 申込6,020件 → 該当5,692世帯**（H13年度2,650世帯から倍増） | [S4][S5] |
| 担い手 | 地域協力員 **R6年度 3,719人**（町内会等60%・地域企業13%・災害防止協力会19%） | [S5] |
| 市の課題認識 | 「**事業開始から20年以上**…**利用世帯数の増加**や、**地域協力員の担い手不足**等の課題」 | [S2][S6] |
| 利用者負担金 | 非課税5,000円 / 課税10,000円 / 生活保護無料（一冬） | [S2] |

**解釈:** 制度は (a) 要介護認定などの要件、(b) 「近くに頼れる子がいない」こと、(c) 地域協力員の手配 —
の3つの関門があり、「まだ元気だが雪かきはつらい」層や「協力員が足りない地域」は制度の外に落ちる。
申込をしても「地域協力員の調整が困難な場合は利用できない」（[S2]）。

### 2.4 地域コミュニティと雪対策の規模

| 指標 | 数値 | 時点 | 出典 |
|---|---|---|---|
| 町内会加入率 | **68.43%**（693,639 / 1,013,633世帯） | R8.1.1 | 札幌市 [S13] |
| 加入率の推移 | 平成元年 **83.01%** → 令和7年 68.86% → 令和8年 68.43%（**約15ポイント低下**） | — | [S13] |
| 町内会数 | 2,163単位町内会 + 90連合町内会 | R8.1.1 | [S13] |
| 雪対策費 | **R7予算 284.8億円** / R6決算 265.2億円（道路除雪費が約8割） | R7/R6 | 札幌市 [S12] |
| 降雪量 | R6年度 累計398cm（平年479cm） | R6年度 | 札幌管区気象台（[S5]内） |

**解釈:** 町内会は「除排雪」を活動に含む地域の担い手だが、加入率は3割の世帯が未加入まで低下。
行政の除雪は年間280億円規模だが、それは「道路」の除雪であり、**玄関前の雪かきは住民の相互扶助に委ねられている**。
